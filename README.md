# 🎓 South Point School Management System

## 📌 Description
A full-stack web application built using Django to manage student records, fees, classes, and sections.

## 🚀 Features
- Student Management
- Class & Section Handling
- Fee Dashboard
- Admin Panel
- Responsive UI

## 🛠 Tech Stack
- Python
- Django
- HTML, CSS, Bootstrap
- SQLite
